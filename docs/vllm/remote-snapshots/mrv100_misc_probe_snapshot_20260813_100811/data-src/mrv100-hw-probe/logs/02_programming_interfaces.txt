List of valid properties to query for the switch "--query-gpu=":

"timestamp"
The timestamp of when the query was made in format "YYYY/MM/DD HH:MM:SS".

"driver_version"
The version of the installed Iluvatar driver. This is an alphanumeric string.

"cuda_version"
The version of the CUDA driver. This is an alphanumeric string.

"count"
The number of Iluvatar GPUs in the system.

"name" or "gpu_name"
The official product name of the GPU. This is an alphanumeric string.

"serial" or "gpu_serial"
This number matches the serial number physically printed on each board. It is a globally unique immutable alphanumeric value.

"uuid" or "gpu_uuid"
This value is the globally unique immutable alphanumeric identifier of the GPU. It does not correspond to any physical label on the board.

"minor_number"
The minor number for the device is such that the Iluvatar device node file for each GPU will have the form /dev/iluvatar[minor number].

"vbios_version"
The BIOS of the GPU board.

"multigpu_board"
On multi-GPU board will set MultiGPU to a non-zero value.

"board_id"
The unique board ID is generated based on the pcie slot connected to the card.

"gpu_position"
Indicates the position of the GPU on the multi-GPU board.

"part_number"
This number indicates the product model number.

"virt.gpu_virt_mode"
The virtualization mode corresponding to the GPU.

"virt.host_vgpu_mode"
If SR-IOV host operation is supported on a vGPU supported device.

"pci.bus_id" or "gpu_bus_id"

"pci.bus"

"pci.device"

"pci.device_id"

"pcie.rx.throughput"
Throughput of RX in PCIe lane of GPU. Represent PCIe utilization information.

"fan.speed"

"memory.total"

"memory.used"
